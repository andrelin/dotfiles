# Style

No `paths:` frontmatter on purpose: this applies everywhere, chat output included, so it loads in every session.

- No all-caps shout words (`IMPORTANT`, `NOTE`, `TODO`, `WARNING`) in prose, docs, code comments or chat output.
- For emphasis, use *italics*, **bold**, or a sentence-case prefix like "Important:" or "Note:".
- Inherently capitalised initialisms are fine: HP, ATK, DEF, XP, ROI, API, URL, AP, APU, ID, UI, JSON, CSV.
- Language-conventional constants in code (`const FOO_BAR`) are out of scope, but lean toward PascalCase or
  camelCase where idiomatic.
- No all-caps filenames: `future-tools.md`, not `FUTURE_TOOLS.md`; `changelog.md`, not `CHANGELOG.md`.
  The exceptions are `README.md`, `CLAUDE.md`, `LICENSE`, `VENDORED.md`, and names a tool requires
  (`SKILL.md`).
